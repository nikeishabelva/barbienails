# Barbie Nails 💅🏻

Website nail art bertema pink + ivory, siap untuk GitHub Pages.

## Fitur
- Gallery 12 contoh nail art
- Filter kategori: All, Pink, Cute, Elegant, Y2K, French
- Nail Creator interaktif
- Pilih warna, desain, dan finishing
- Random Design
- Responsive desktop & mobile
- Tanpa backend, cukup HTML/CSS/JS

## GitHub Pages
Upload `index.html` dan `README.md` ke repository GitHub.
Lalu buka Settings → Pages → Deploy from branch → `main` → `/root`.
